# About
Fumi is a programming language made for recreational and learning purposes.

# Dependencies
Mektova-C-Utils : https://github.com/yuumei-02/Mektova-C-Utils <br>
Vlodinnye-make  : https://github.com/yuumei-02/Vlodinnye-make <br>

# Building the project
To build the project, bootstrap the build system by running the following command inside the project root folder.
```shell
gcc -std=c23 vmake.c -o vmake -lmcu-debug
```
Then, just run ```./vmake build``` and your done.
